# Runbook 02: RBAC Registration — Hub Daily Shift Reports

## 1. Objective

Register the three Hub Reports permission flags into the PowerProject RBAC system across four files. After this phase:

- `canAccessHubReports` — controls sidebar visibility (Viewer+)
- `canSubmitHubReports` — controls the Maker's "Submit Draft" action (Contributor+)
- `canVerifyHubReports` — controls the Checker's "Verify Report" action (Editor+)

These flags propagate automatically through the existing `useRBAC` hook machinery — no changes to `ContentRouter.jsx` are needed.

### 4.3 — MODIFY `src/verticals/DataManager/DataManagerSubSidebar.jsx`

**BEFORE** (full current file — 37 lines):

const DataManagerSubSidebar = ({ activeVertical, setActiveVertical, permissions }) => {

## 6. Troubleshooting & Gotchas

| Issue | Potential Cause | Fix |
| :--- | :--- | :--- |
| Hub Reports button does not appear | `canAccessHubReports` is `undefined` instead of `true` | Verify the flag is in `masterPerms` AND `features` array in `useRBAC.js`. |
| Button appears but clicking it shows the Data Sheet Board | `rootVerticalId` normalisation for `'hub_reports'` is missing | Add `current === 'hub_reports'` to line 79 of `useRBAC.js`. |
| RBAC settings UI does not show Hub Reports feature | Feature not added to `verticalFeatures.js` | Re-check step 4.1. |
| `canSubmitHubReports` is `undefined` for non-master users | Feature string mismatch in `features` array (PascalCase) | Confirm `'SubmitHubReports'` (not `'Submit_Hub_Reports'`) is in the array. |
